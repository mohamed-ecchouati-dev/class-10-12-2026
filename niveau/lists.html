List Types

Ordered List
A list that displays items in a numbered sequence.
Uses types: 1, A, a, I, i
Unordered List
A list that displays items in a bulleted sequence.
Uses types: disc, circle, square
Description List
A list that pairs terms with their descriptions.
Uses 2 forms: dt, dd
